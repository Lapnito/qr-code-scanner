## 什么是二维码扫描器？

**二维码扫描器**（在 App Store 上以 *QR code reader without ads* 发布）是一款适用于 Android 与 iPhone 的快速免费二维码识别器。可使用相机扫码，也可识别相册中带有二维码的图片。无广告、无需账号，扫码记录仅保存在你的设备上。适合登机牌、餐厅菜单、Wi-Fi 二维码、付款码、名片、包裹追踪、活动门票、博物馆语音导览，以及日常生活中遇到的任何二维码。

理念只有一个：**扫描，看到结果，自行决定** — 仅此而已。无广告、无弹窗、无追踪。

## 主要功能

### 扫描
- **相机即时扫描** — 把手机对准二维码，应用立即识别
- **从图片扫描** — 从相册选择任何含有二维码的图片
- **离线可用** — 扫码无需网络

### 结果
- **打开链接** 一键操作（打开前可预览 URL）
- **复制** 解码内容到剪贴板
- **分享** 结果给任何应用，使用系统的分享菜单

### 历史
- **本地扫码记录** — 每次扫码都保存在设备上
- **搜索与查看** 历史扫码
- **删除条目** 或一次清空整个历史

### 隐私与体验
- **无广告** — 没有横幅、没有插屏、没有赞助
- **无注册** — 没有账号、邮箱、密码
- **无追踪** — 扫描内容与历史不会离开你的设备
- **轻量** — 体积小、耗电低、启动快

## 工作原理

**应用如何解码二维码？**
通过设备相机和内置 QR 解码器。所有图像在本地处理 — 不会上传任何内容。

**可以扫描图片吗？**
可以。打开应用内的相册选择器，选择含有二维码的图片或截图。

**扫码记录保存在哪里？**
仅保存在你的设备上。不与服务器同步；卸载应用即清除。

**没有网络可以使用吗？**
可以。识别完全离线。仅在打开链接时需要网络。

**会有广告吗？**
不会。应用不含任何形式的广告。

## 常见问题

**真的免费吗？**
是。免费下载与使用，不含广告与应用内购。

**需要注册账号吗？**
不需要。无注册、无登录、无邮箱。

**会收集我的数据吗？**
不会。扫描内容与历史保留在设备上，不会发送到我们的服务器。

**也能识别条形码吗？**
应用针对二维码优化。一维条形码不是主要使用场景。

**为什么需要相机权限？**
这是实时识别二维码的唯一方式。相机仅用于扫码。

**为什么需要照片权限？**
仅用于让你从相册选择含二维码的图片。没有其他用途。

**打开二维码中的链接安全吗？**
打开前请先查看 URL。来自未知来源的二维码可能指向钓鱼页面。

**支持哪些设备？**
带相机的 Android 设备，以及 iOS 13.0 或更高版本的 iPhone / iPad。

**离线可用吗？**
是。扫码、解码、历史完全离线。仅打开链接需要网络。

**如何反馈错误？**
在 [github.com/Lapnito/qr-code-scanner/issues](https://github.com/Lapnito/qr-code-scanner/issues) 提交 issue，或邮件至 tom@lapnito.cz。
