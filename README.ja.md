## QRコードスキャナーとは？

**QRコードスキャナー**（App Storeでは *QR code reader without ads* として配信）は、Android / iPhone 向けの高速・無料QRリーダーです。カメラでスキャンする方法と、ギャラリーの画像から読み取る方法に対応します。広告は一切なく、アカウントも不要、スキャン履歴は端末内にだけ保存されます。搭乗券、レストランのメニュー、Wi-Fiコード、決済QR、名刺、荷物追跡、イベントチケット、博物館の音声ガイドなど、日常で出会うあらゆるQRコードに使えます。

シンプルな考え方：**読み取る、結果を見る、自分で決める** — それだけ。広告なし、ポップアップなし、トラッキングなし。

## 主な機能

### スキャン
- **カメラで即時スキャン** — 端末をQRに向けるだけで瞬時に読み取り
- **画像からスキャン** — ギャラリー内のQRを含む画像を選んで読み取り
- **オフライン動作** — 読み取りにインターネットは不要

### 結果
- **リンクを開く** ワンタップで（開く前にURLをプレビュー）
- **コピー** デコード結果をクリップボードへ
- **共有** システムの共有メニューから任意のアプリへ

### 履歴
- **ローカルのスキャン履歴** — すべての読み取りを端末に保存
- **検索・再閲覧** 過去のスキャンへ
- **個別削除** または履歴の全消去

### プライバシーと使い心地
- **広告なし** — バナーも全画面もスポンサーもなし
- **登録なし** — アカウント不要、メール不要、パスワード不要
- **トラッキングなし** — 読み取り内容と履歴は端末から外へ出ない
- **軽量** — 容量が小さく、電池消費が少なく、起動が速い

## 仕組み

**どうやってQRをデコードしているの？**
端末のカメラと内蔵QRデコーダーを使用します。フレームは端末内で処理され、何もアップロードしません。

**画像からも読み取れる？**
はい。アプリ内のギャラリー選択を開き、QRを含む写真やスクリーンショットを選んでください。

**履歴はどこに保存される？**
端末内のみ。サーバーへの同期はなく、アンインストールすると消えます。

**インターネットなしでも動く？**
はい。デコードは完全にオフラインです。リンクを開くときだけ通信が必要です。

**広告は表示される？**
いいえ。アプリには一切の広告が含まれていません。

## よくある質問

**本当に無料ですか？**
はい。ダウンロードも利用も無料、広告もアプリ内課金もありません。

**アカウントは必要ですか？**
いいえ。登録、ログイン、メールアドレスは不要です。

**データは収集されますか？**
いいえ。読み取り内容と履歴は端末に残ります。当社サーバーには何も送信されません。

**バーコードも読めますか？**
本アプリはQR向けに最適化されています。1Dバーコードは主な用途ではありません。

**カメラ権限はなぜ必要？**
リアルタイム読み取りのためです。カメラはスキャン以外には使いません。

**写真権限はなぜ必要？**
ギャラリーからQRを含む画像を選ぶためだけに使います。それ以外の用途はありません。

**QRのリンクは安全？**
開く前に必ずURLを確認してください。出所不明のQRはフィッシングへ誘導することがあります。

**どの端末で使える？**
カメラ搭載の Android 端末と、iOS 13.0 以降の iPhone / iPad。

**オフラインで使える？**
はい。スキャン、デコード、履歴は完全オフラインで動作します。リンクを開くときだけ通信が必要です。

**不具合の報告は？**
[github.com/Lapnito/qr-code-scanner/issues](https://github.com/Lapnito/qr-code-scanner/issues) に issue を立てるか、tom@lapnito.cz までご連絡ください。
