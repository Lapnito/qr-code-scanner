## QR 코드 스캐너란?

**QR 코드 스캐너**(App Store 출시명 *QR code reader without ads*)는 Android·iPhone용 빠르고 무료인 QR 리더입니다. 카메라로 즉시 인식하거나 갤러리의 이미지에서 QR을 읽을 수 있고, 광고 없이 계정 없이 사용하며, 스캔 기록은 기기에만 저장됩니다. 탑승권, 레스토랑 메뉴, Wi-Fi 코드, 결제 QR, 명함, 택배 추적, 행사 티켓, 박물관 음성가이드 등 일상에서 만나는 모든 QR 코드에 적합합니다.

원칙은 하나: **스캔하고, 결과를 보고, 결정한다** — 그게 전부입니다. 광고도, 팝업도, 추적도 없습니다.

## 주요 기능

### 스캔
- **카메라 즉시 스캔** — 폰을 QR에 맞추면 곧바로 인식
- **이미지에서 스캔** — 갤러리에서 QR이 포함된 사진 선택
- **오프라인 작동** — 인터넷 없이도 코드 인식

### 결과
- **링크 열기** 한 번의 터치로(열기 전에 URL 미리보기)
- **복사** 디코드된 내용을 클립보드로
- **공유** 시스템 공유 메뉴로 어떤 앱에든

### 기록
- **로컬 스캔 기록** — 모든 스캔이 기기에 저장
- **검색·재방문** 과거 스캔
- **항목 삭제** 또는 전체 기록 비우기

### 개인정보 보호와 사용성
- **광고 없음** — 배너·전체화면·스폰서 모두 없음
- **가입 없음** — 계정·이메일·비밀번호 모두 불필요
- **추적 없음** — 스캔 내용과 기록은 절대 기기를 떠나지 않음
- **가벼움** — 작은 용량, 낮은 배터리 소모, 빠른 실행

## 사용 시나리오

| 상황 | 앱이 하는 일 |
|------|---------------|
| 레스토랑 메뉴 | 테이블 QR 스캔 후 메뉴 열기 |
| Wi-Fi 공유 | Wi-Fi QR을 읽어 네트워크 정보 표시 |
| 탑승권 | 인쇄된 QR을 보관용으로 디코드 |
| 행사 티켓 | QR을 읽고 예약번호를 복사·공유 |
| 명함(vCard QR) | 연락처 정보 디코드 |
| 결제 QR | 결제 전 목적지 URL/문자열 표시 |
| 택배 추적 | 패키지 QR 스캔 후 배송조회 페이지 열기 |

| 오프라인 스캔 | 비행기, 지하철, 지하실에서도 인식 |

## 작동 원리

**앱은 어떻게 QR을 디코드하나요?**
기기 카메라와 내장 QR 디코더를 사용합니다. 프레임은 기기 안에서 처리되며 어떤 데이터도 업로드되지 않습니다.

**이미지로도 스캔할 수 있나요?**
네. 앱 안의 갤러리 선택기를 열어 QR이 포함된 사진이나 스크린샷을 고르면 됩니다.

**기록은 어디에 저장되나요?**
기기 내부에만. 서버 동기화는 없으며 앱을 삭제하면 함께 사라집니다.

**인터넷 없이도 동작하나요?**
네. 디코드는 완전히 오프라인입니다. 링크를 열 때만 연결이 필요합니다.

**광고가 보이나요?**
아니요. 어떠한 형태의 광고도 포함되어 있지 않습니다.

## 자주 묻는 질문

**정말 무료인가요?**
네. 다운로드와 사용 모두 무료, 광고와 인앱 결제도 없습니다.

**계정을 만들어야 하나요?**
아니요. 가입·로그인·이메일 모두 필요 없습니다.

**제 데이터를 수집하나요?**
아니요. 스캔 내용과 기록은 기기에 남아 있고, 저희 서버로는 아무것도 전송되지 않습니다.

**바코드도 읽나요?**
앱은 QR에 맞춰 최적화되어 있습니다. 1D 바코드는 주요 용도가 아닙니다.

**카메라 권한은 왜 필요하나요?**
실시간으로 QR을 인식하는 유일한 방법이기 때문입니다. 카메라는 스캔 외에는 사용되지 않습니다.

**사진 권한은 왜 필요한가요?**
갤러리에서 QR이 포함된 이미지를 고르기 위해서만 사용됩니다. 다른 용도는 없습니다.

**QR 링크를 여는 게 안전한가요?**
열기 전에 항상 URL을 확인하세요. 출처를 알 수 없는 QR은 피싱 페이지로 연결될 수 있습니다.

**어떤 기기에서 동작하나요?**
카메라가 있는 Android 기기와 iOS 13.0 이상의 iPhone / iPad.

**오프라인에서도 되나요?**
네. 스캔·디코드·기록은 모두 오프라인으로 동작합니다. 링크를 열 때만 인터넷이 필요합니다.

[github.com/Lapnito/qr-code-scanner/issues](https://github.com/Lapnito/qr-code-scanner/issues) 에 issue를 등록하거나 tom@lapnito.cz 로 메일 주세요.
